# 实验目录分类与平台自动发现实施计划

**目标：**按已批准方案迁移 147 个实验，并让只读平台按目录和 metadata 自动发现档案。

**设计：**[设计说明](../specs/2026-10-31-experiment-directory-catalog-design.md)。

**技术：**Python/JSON、现有 FastAPI 与原生 JavaScript；不引入额外依赖。

## 全局约束

- 保持 150 条历史事件顺序、147 个 ID、详情字节/哈希及指标不变。
- 保留原有工作区未提交改动；本任务不提交、推送或创建另一份工作区。
- 按 models/<原 exp_id> 与 strategies/<原 exp_id> 存放；共享及系统目录保留。
- 元数据发现不替代历史账本；正式登记自动维护元数据。
- 平台保持只读，原 36 条记录的指标与比较资格保持不变。
- 不训练、回测，不清理模型/session/MLflow，不改研究口径。
- 一次性工具和账本位于 /private/tmp/qlib-experiment-kind-layout-20261031，验收后删除。

## 重点验证

新增未登记文件夹、重复 ID、kind/目录冲突、越界或符号链接、损坏指标/详情、较新事件损坏、缺失档案、跨轨道比较及并发追加。

正式登记须写回新目录，不能仅迁移现有文件后让新写入重建旧路径。历史指标仅来自声明的原有 JSON 或带来源标识的登记摘要，不补造缺失值。

## 完成记录
