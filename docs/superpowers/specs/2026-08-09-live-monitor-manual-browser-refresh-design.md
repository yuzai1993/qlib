# 实盘监控手动浏览器刷新与前端性能优化设计

## 目标

取消实盘监控 SPA 的自动轮询与自动重绘。监控数据只在用户刷新浏览器页面时重新获取，同时修复单页切换过程中遗留的图表资源、过期请求覆盖和预测页首屏阻塞，使页面长时间打开或反复切页后仍保持稳定。

## 现状与根因

概览页当前通过 `setInterval` 每 60 秒调用 `navigate('dashboard')`。这条路径会先用“加载中”替换整个主内容区，再请求 `/api/overview` 与 `/api/nav`，最后新建 ECharts 实例并重新播放折线动画。运行中观察到数据未变化时图表实例 ID 仍在一个刷新周期后改变，证明曲线的“持续刷新”来自整图重建，而不是净值数据持续变化。

每次调用 `drawNavChart` 或 `loadPredMeanChart` 都会注册新的匿名 `resize` 监听器。旧 DOM 被替换前没有统一释放 ECharts 实例，监听器闭包会继续引用旧图表；自动刷新或反复切页会因此持续积累资源。异步页面渲染也没有页面世代校验，旧页面请求可能在用户切页后返回并覆盖当前内容。

预测页进入时把 `/api/predictions/dates` 和约 72 KB 的 `/api/predictions/instruments` 作为同一个首屏阻塞阶段，之后才建立页面结构并加载摘要、曲线和表格。实测预测页首次可见表格约需 1.3 秒，而热态 `/api/overview` 和 `/api/nav` 分别约为 17 ms 和 6 ms，因此本次优化以浏览器端生命周期和加载顺序为主，不改后端接口。

## 已选方案

页面不增加“刷新”按钮，也不显示自定义刷新状态或最近刷新时间。用户需要获取新数据时，直接使用浏览器自带的刷新操作；浏览器重载会重新获取全部页面资源和监控数据，并天然销毁上一页面上下文。

删除 `refreshTimer`、`scheduleRefresh()` 和所有自动定时调用。页面保持静止，不因可见性变化、固定时间间隔或切回标签页而发起后台刷新。

## 前端生命周期

前端维护唯一的活动图表引用和唯一的窗口缩放处理函数：

1. 绘制净值图或预测均值图前，先释放当前活动图表。
2. 用户切换 SPA 页面、页面渲染失败或目标数据为空时，释放当前活动图表。
3. 窗口缩放时只调整当前仍存活的图表，不为每个实例增加匿名监听器。
4. 浏览器整页刷新仍由浏览器销毁整个页面上下文，不需要额外的页面刷新协议。

该约束保证任意时刻最多只有一个 ECharts 实例由 SPA 持有。概览曲线在普通停留期间不再重建或重新播放动画。

## 页面请求与渲染

每次用户导航都会生成递增的页面世代标识。异步渲染函数在写入 DOM 前确认其页面名称与世代仍是当前值；用户已经切到其他页面时，旧请求结果被静默丢弃。错误同样只允许由当前页面显示，避免旧请求的错误替换新页面。

导航开始时可以显示现有“加载中”状态，因为这是用户主动切页；取消自动刷新后，不再存在后台刷新导致的周期性闪烁。当前 API 路径、响应结构和只读边界保持不变。

## 预测页首屏

预测页先请求日期列表并建立页面结构，然后并行加载摘要、均值曲线和首张明细表。标的联想列表不再阻塞主体内容：它在页面结构建立后独立加载，并在当前浏览器会话内缓存。

再次进入预测页时复用已加载的标的列表。浏览器整页刷新会清空缓存并重新获取，符合“浏览器刷新即全量刷新”的统一语义。联想列表尚未就绪时，普通日期选择、分页和代码查询仍可使用；自动补全在数据到达后自然可用。联想列表请求失败不得阻止摘要、曲线和表格显示。

## 错误处理

- 当前页面的主要请求失败时，沿用现有“加载失败”提示。
- 已离开的页面请求无论成功或失败都不得修改当前 DOM。
- ECharts 初始化或数据为空前先清理旧活动实例，避免错误路径保留资源。
- 标的联想列表加载失败仅禁用本次会话的自动补全，不影响预测主体页面；重新加载浏览器页面可重试。

## 测试设计

新增可由 Node 直接执行的前端行为测试，并由 pytest 包装调用，使其进入现有 `tests/live_trading` 测试流程。测试针对可观察行为，而不是搜索源代码文本：

1. 应用启动后不创建自动刷新定时器，等待不会产生额外 API 请求。
2. 页面切换会释放旧图表，连续切换后仅当前图表响应缩放。
3. 较早请求在较晚导航后完成时不能覆盖当前页面或当前错误状态。
4. 预测页主体数据不等待标的联想列表即可显示。
5. 标的列表在同一会话内只成功加载一次；加载失败不阻断主体页面。

现有 FastAPI 端点测试继续通过，以证明本次修改没有改变 API 响应和只读操作边界。浏览器验收会复核概览静置超过 60 秒后图表实例 ID 不变，并反复切换概览与预测页确认无控制台错误。

## 验收标准

- 概览页静置超过 60 秒时不新增 `/api/overview` 或 `/api/nav` 请求，曲线不闪烁、不重画。
- 页面没有自定义刷新按钮；浏览器刷新后能显示数据库中的最新数据。
- 反复切换含图表页面时，旧图表被释放且窗口缩放只作用于当前图表。
- 过期页面请求不覆盖当前页面。
- 预测页主体不被全量标的列表阻塞，联想列表在会话内复用。
- 前端行为测试、现有监控 Web API 测试和代码格式检查全部通过。

## 范围外事项

本次不修改监控数据生成、盘后流水线、告警、交易发布、SQLite 表结构、REST API、刷新频率配置或浏览器缓存策略。也不引入 WebSocket、服务端推送、增量轮询或新的前端框架。
