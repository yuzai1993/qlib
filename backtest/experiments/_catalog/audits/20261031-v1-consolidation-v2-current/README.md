# H20 v1归并与当前模型v2

2026-10-31，按用户要求，将H20训练目标（v1）独立条目归并为训练目标汇总内的历史对照来源，并把当前全A模型明确选为Top5早停v2。

- 原v1活动索引和独立目录已移除，冻结来源原字节迁至`models/training-target/horizon-comparison/baseline-records/`。顶层`historical_baselines`按相对路径与SHA256引用它，仅用于历史对照、模型说明和模型产物保留，不恢复为活动实验或当前基线。

- 使用正式登记入口为v2追加一次当前选择事件，保留原训练日期、配置、指标及原有登记字节；选择日期另记2026-10-31。版本号没有重排，v3/v4及其当时对照仍是历史事实。
- 平台和模型总报告均以v2为当前；只有活动登记能决定当前选择，历史来源不能参与当前版本推断。实验规范、AGENTS与guide同步更新。执行基线仍为BT v5，生产配置未变。
- 清理器复用同一历史来源读取器，继续保护v1等四代模型五种子原件。实际只读计划无错误，保留24个结果目录，未执行删除。

现有28个独立实验（6模型、22策略）；29行索引包含v2的后续选择事件。模型总报告保留4代历史baseline，独立实验列表没有重复v1条目。
