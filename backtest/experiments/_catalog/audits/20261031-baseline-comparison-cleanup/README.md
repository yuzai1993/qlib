# 实验对照表与重复实验清理

2026-10-31，按用户要求，将实验详情的核心指标统一为当时Baseline与实验组的固定对照表；模型Benchmark仍保留单版本介绍及分年、分风格视图。没有恢复手动比较功能。

- 对照严格按登记的历史引用及版本读取，不用当前版本替换。v4单种子集成对照读取v4源JSON种子42的Top3×H5指标，净年化24.30%；不拿五种子合成30.57%冒充同种子结果。
- 初始基线没有前版，Baseline行明确空置。来源缺失、版本或身份不符、匹配种子缺失或对照失败时也保留空值，注明原因。失败实验不展示残留指标；不同窗口或资金费用诊断只并列参考。
- 删除H1/H5/H10三个重复独立档案与活动登记，完整源JSON和冻结来源记录归入训练目标汇总；H1/H5/H10/H20（v3）的四组指标保持不变。汇总源记录只参与该表，不恢复为独立实验或晋升基线。
- 删除v3单种子集成独立档案和活动登记，保留五种子实验。没有删除模型原件、共享资料或生产文件。
- 五种子集成原有两条报告入口实际指向同一HTML，现保留一个可用入口。平台按安全解析后的文件去重，隐藏不可用报告入口，原登记和非报告缺失审计证据仍保留。

当前29个实验（7模型、22策略）。模型总报告已由正式生成器重建；目录guide进展和实验README已更新。未训练、回测或晋升。
