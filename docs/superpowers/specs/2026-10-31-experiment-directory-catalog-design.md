# 实验目录分类与平台自动发现

依据用户已批准的方案实施：实验按模型、策略分目录；新增实验目录和元数据后，平台刷新即可发现和展示。平台保持只读。

## 目录与身份

```text
backtest/experiments/
  models/<原 exp_id>/
  strategies/<原 exp_id>/
  reports/
  _shared/
  _catalog/
  registry.jsonl
```

原实验 ID、历史 baseline_ref、150 条事件的顺序和全部详情 JSON 原字节不变。147 个实验初分为模型侧 91 个、策略/执行回测侧 56 个。模型侧也包含评估诊断；策略侧也包含模型变化的执行回测，使用 activity、role、changed_axes 说明实际研究内容。

每个实验继续就近保存配置、报告、说明、指标及 records。公共报告、冻结预测和共享依赖保留唯一来源。模型原件、mlruns 与 result 不迁移或清理。

## 元数据与登记

升级实验 metadata：schema_version=2、entity_type=experiment、exp_id、kind=model|strategy、track=all_a|csi1000、title，以及可选 activity/role、指标源、配置、报告、说明和缺失资料信息。

目录类别必须与 kind 一致；ID 全局唯一。指标源优先使用已登记 portable JSON，原始指标缺失必须如实显示；元数据不复制详细指标。元数据仅定义档案和资源位置，正式状态、晋升与历史来自 registry。

新增合规目录即可显示未登记档案；正式登记入口自动创建或刷新档案元数据与索引。无需人工维护平台列表。不能把未登记档案作为官方基线或正式可比实验。

引入兼容的 v3 索引定位协议，将逻辑 ID 与 models/strategies 物理位置分开；继续读取内联、v1、v2。历史详情只搬文件，不重新序列化或重写其中的来源路径。追加新事件仍经过共享登记入口和稳定锁。

路径映射保留 old→current→new 的明确链，保持原始资产身份，避免多个前驱导致歧义。共享 parity 元数据不属于实验。

## 平台

扫描 models 与 strategies 下的实验 metadata，刷新请求重新发现。安全检查包括目录类别、ID、相对路径、边界、符号链接、大小和哈希；损坏或重复档案明确提示，不猜测替代。

147 个已登记档案全部可查看。原有 36 个全A条目的指标、种子证据、状态、当前基线和可比性保持不变。历史 CSI1000 使用其原有指标适配；缺少可核验来源的条目标为历史摘要或缺失，禁止伪装成正式指标源。

页面增加 CSI1000/全A轨道筛选，按 track、kind 和协议划分指标、基线和比较范围。默认仍展示现有全A轨道。后台不执行训练、回测、模型反序列化或清理。

## 验收

- 150 个逻辑事件逐条相等，147 个稳定 ID；详情字节、哈希及所有数值不变。
- 实验目录 91/56 分类与 metadata 一致；归档资源存在且配置哈希一致。
- 新目录无需改 registry 或平台代码即可被发现；正式写入不会重建旧目录。
- 原有 36 条平台数值、状态和比较判定不变；所有 147 个档案可查。
- 清理 dry-run 结果不变；当前 Top5 和历史 K1 配对检查通过。
- HTML 正文与数值保留，必要本地链接跟随新位置更新。
- 平台服务加载新代码并验证页面；只重载平台，不运行或重启交易调度。
- 更新目录指南进展，删除本任务一次性工具与工作副本，保留正式模块、复用测试及审计 JSON。
