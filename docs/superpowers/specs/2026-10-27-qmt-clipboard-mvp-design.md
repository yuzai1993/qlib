# QMT 剪贴板最小交易器

状态：用户已于 2026-10-27 批准开发；假设 QMT 可读写 Windows 剪贴板。

## 边界

新增两个可一起复制到 Windows 的标准库 Python 脚本。QMT 脚本兼容 Python 3.6、ASCII 源码，完全不调用文件或网络 I/O；外部中转脚本负责读指令 JSON 和保存输出。固定本地账户，只支持明确股数和限价的股票买卖，收到立即提交。保留原生产实现，不自动部署或真实下单。

## 取舍

已讨论单向剪贴板与双向持久化桥接；用户选择进一步简化的双向内存执行器。删除旧协议兼容、外部持久化确认、自动恢复、策略计算、阶梯抵销、预算缩量、交易时点、多通道、自动撤单重报、账户快照和对账。异常交由人工处理。

## 协议

UTF-16 Windows 文本剪贴板中的 JSON，固定 `protocol=qlib-clipboard-v1`。请求为 `trade` / `poll`，响应为 `response`。每个请求有 request_id；trade 必须携带当前 session、带时区的 expires_at 和 orders（id/symbol/side/quantity/price）。poll 可以不带 session 进行发现；已绑定会话的请求不接受会话变化。

单个中转客户端、一问一答、只允许一个未完成请求；超时重试原请求。读写使用剪贴板锁，响应替换前比较当前文本，避免覆盖后来请求。QMT 按订单 ID 内存去重，下单前登记，同 ID 不同内容整请求拒绝。整批先校验再提交。重启更换 session；中转不得把旧交易绑定到新会话。

输出为本次会话完整订单快照和最近 100 条递增编号日志。查询使用券商累计成交数据，不累计重复回调。保留已观察成交，不因查询缓存回退减少成交。提交返回不代表成交；异常标记 UNKNOWN，绝不自动重下。已发出的委托不会随策略停止而撤销。

`clipboard_relay.py`：status/send/watch CLI，原样重试、会话校验、结果 JSON 和日志 JSONL。
示例交易 JSON、中文部署说明、模拟券商/剪贴板测试。测试不触发真实交易。Windows/QMT 实机可用性仍须用户本机验证。
