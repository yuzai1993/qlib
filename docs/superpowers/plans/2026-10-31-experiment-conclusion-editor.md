# 实验结论预填与表格编辑实施计划

**目标：**按现有证据预填精简结论，并让模型、策略实验表格支持行内编辑。用户追加要求删除报告缺失的实验。

**方案：**结论存于实验 `metadata.json.analysis`，原登记、指标和比较权限保持原定义。采用行内编辑直接保存到文件，与当前目录维护方式一致；浏览器本地存储不能满足文件持久化，改写冻结 registry 会破坏历史，因此不采用。删除无可读报告的两个模型档案和对应事件，其余 33 条原登记内容及索引行保留。

**接口：**`PUT /api/research/conclusion` 接收 `{id, conclusion, revision}`；结论去首尾空白后为1–500字符，版本为元数据SHA-256。服务端沿用本机、同源和CSRF校验，只定位经目录扫描确认的元数据；持锁检查版本、只更新结论及编辑日期/草稿状态、原子保存。冲突返回409。
