# 离线实验展示调整

依据：2026-10-29 用户明确要求模型实验、策略实验各有 Benchmark 和实验记录两个子模块。

沿用现有本地量化平台、研究源及只读数据接口。在原 qlib 工作区实施，遵循此前已确定的 main 集成方式。

- 2026-10-30 用户修订：左侧以模型实验、策略实验两个入口替换离线实验；各保留 Benchmark、实验记录。移除页面顶部统计卡。
- Benchmark 核心指标始终展示全部已晋升 baseline，按版本从新到旧排列，首列为勾选框，表头支持全选/清空。不另设版本选择框。勾选只影响下方分维度表，模型/策略分别保存，不与正式实验对比选择混用。
- 核心指标下设分风格、分年两个页签。核心指标行=版本、列=指标；分维度每指标一表，行=版本、列=年度或 D/F/T。单次实验详情和正式对比复用同一指标表渲染器。
- 策略展示去除算术年化，核心表紧凑排版：缩短表头、保留完整口径提示、隐藏占宽的源 ID、减小单元格留白，使全部核心列能在一屏内展示。
- 年份取数据与评估窗口覆盖的并集；风格固定 D/F/T 并保留源中额外维度。缺失值显示 —，不从全期回填；全局 RankIC 不铺进分维度。
- 实验记录主要列为日期、实验内容、结论、报告链接、晋升版本，保留详情与同口径对比能力。版本只读明确的 baseline 标记，不由分数、对照版本或结论猜测晋升。
- 结论保留独立字段；有详细备注时同时展示。报告使用现有受控资源 ID 预览和下载；缺失报告明确标记。
- CSV 对应当前已选版本、视图和筛选；分维度导出保留指标及全部维度。

实现选择：复用 API 并抽取轻量共享展示模块。继续维持四个平级视图不符合用户指定层级；另建页面会重复指标逻辑，因此不采用。

验证：Node 行为测试覆盖默认选择、空选、跨模块选择、维度矩阵、结论/晋升/资源、CSV；Python 验证新增元数据；浏览器检查实际研究数据及窄屏。范围仅展示工程，不运行实验或修改研究登记、交易数据与配置。
