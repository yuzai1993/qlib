# 训练目标期限对比

这里是已有训练目标实验的汇总入口。固定Top3选股、持有5日，以及Top3×H5净年化早停，比较训练标签H1、H5、H10、H20。各组五种子信号先按日截面z-score再等权合成，分别评估，不在不同H之间融合。

本研究条目标记为**产出v1 Benchmark**，由`metadata.json.benchmark_outputs`登记产出关联。v1在Benchmark中展示，不恢复为独立实验记录；当前模型仍为v2。该关联按用户确认的研究归属维护，不重写原始登记事件。

主结果直接引用各组已登记的源JSON：H1 −39.79%、H5 24.77%、H10 24.37%、H20（v3）29.70%，H20最高。H1/H5/H10没有全局RankIC，保持缺失。对照是v3 H20，不能用Top5早停v2的30.19%替代。未重新训练或回测。

`metadata.json.training_target_comparison`登记原实验引用与对照；`archived_records`按相对路径和SHA256引用`source-records/`内的H1/H5/H10冻结来源记录，H20对照仍引用独立v3基线。三组完整指标JSON统一保存在本目录`metrics/`，不再单独维护H1/H5/H10实验目录或活动登记。数值由这些来源读取，不在元数据重复手写。缺失、失败、种子不全或评估协议不同时暂停汇总，不回退旧网格数值。同一历史窗已用于早停及选型，不能视为独立样本外结论。
