# A 股赢家画像驱动的最小风格划分设计

日期：2026-08-09

状态：待用户审阅

研究性质：`diagnostic_no_selection`

适用范围：A 股 2006 年至今的定量风格划分，以及 1990～2005 年的定性映射

## 1. 目标与结论边界

本研究要寻找满足以下条件的**最小市场状态数**：

1. 不同状态下，能产生收益的股票类型存在足够大的、可重复的差异；
2. 每个时期都能归入一个状态，不能只给牛市、危机或政策行情贴事件标签；
3. 在满足前两条的前提下，状态数量越少越好。

状态从股票类型的实际收益规律中发现，不预先命名为牛市、熊市、机构牛或题材牛。状态名称只在聚类完成后，根据冻结的赢家画像解释性命名。

本研究是市场结构诊断，不训练或晋升 B6-M，不修改 B4-S，不把任何状态回测描述为可直接交易的收益承诺。若未来把状态用于模型特征或策略路由，必须另立 Phase M 或 Phase S 实验。

## 2. 三个核心定义

### 2.1 “股票类型”

股票类型由可在当时获得的截面特征定义，而不是由股票名称、行业故事或事后涨幅定义。主分析使用六个相对独立的特征族：

| 特征族 | 主要字段/表达式 | 正方向解释 |
|---|---|---|
| 规模 | `log(total_mv)`、`log(circ_mv)` | 大盘；报告同时给小盘的相反方向 |
| 估值 | earnings yield、book-to-price、sales-to-price | 价值 |
| 质量/增长 | ROE、毛利率、营收同比、利润同比 | 高质量、基本面成长 |
| 趋势 | 20 日动量、120 日动量（剔除最近 20 日） | 中期趋势占优 |
| 风险/防御 | `-beta60`、`-特质波动率60`、`-回撤120` | 低 beta、低波、防御 |
| 交易/投机 | 换手率、换手加速度、低价、涨停频率、特质偏度 | 高换手、彩票型、题材活跃 |

规模、估值、质量和增长依赖 PIT 外部字段；趋势、风险和部分交易特征来自本地 Qlib 前复权 OHLCV。每个原始字段先按月做 median/MAD 标准化并裁剪到 `[-3, 3]`，按表中方向对齐后在特征族内等权平均；一个特征族至少一半子字段有效才生成该股的族分数。除规模特征本身外，其余特征族再对行业哑变量和 `log(total_mv)` 做截面残差化，避免把“价值有效”误写成“小盘有效”。

### 2.2 “产生收益”

以月 `t-1` 最后一个交易日当时可见的股票特征，解释月 `t` 的逐股收益。月收益先在截面 1%/99% 分位裁剪，再对完整六族样本运行带行业固定效应的 Ridge 回归（`alpha=1.0`、等权、行业哑变量 drop-first）：

```text
next_month_stock_return
    = industry_effect
    + beta_size × size
    + beta_value × value
    + beta_quality × quality
    + beta_trend × trend
    + beta_defensive × defensive
    + beta_speculative × speculative
    + residual
```

六个标准化系数构成月 `t` 的**赢家画像向量**。正系数表示该类型在月 `t` 获得收益补偿，负系数表示相反类型占优。稳健回归用于减少涨跌停、壳股和极端收益对状态的支配；同时保留各特征族最高/最低十分位的等权收益差作为非参数复核。

### 2.3 “覆盖所有时期”

- 2006 年至最新完整月份：每个月必须且只能分配到一个状态；不允许 `unknown` 逃避困难月份。
- 超出历史支持的月份仍分到最近状态，但同时报告到最近状态中心的距离；若冻结审计段 OOD 月份超过 5%，则当前状态数不满足“覆盖”，必须增加状态或否定简化方案。
- 1990～2005：因逐股 PIT 数据不足，按公开市场史、指数、成交与已知主导股票类型映射到定量状态，逐段给出置信度；这部分只证明叙事覆盖，不与 2006 年后的定量显著性混用。

## 3. 数据范围与第一道停止门

### 3.1 股票池

定量主池为 PIT 全 A 股：

- 使用当日已经上市且可交易的沪深 A 股；
- 剔除上市不足 60 个交易日的股票；
- ST 名称缓存可用时剔除 ST，无法取得时必须单独报告；
- 不能用当前成分倒灌历史，也不能只保留截至今天仍上市的股票；
- 行业分类必须按当时有效的分类或至少按公告日期可追溯。

### 3.2 数据源

1. 本地 Qlib：2003 年起的前复权 OHLCV、交易日历和 `all` PIT 股票池；
2. PIT 市值与估值：优先使用可审计的 Tushare `daily_basic` 月末快照，字段包括 `total_mv/circ_mv/turnover_rate/pe_ttm/pb/ps_ttm`；
3. PIT 财务质量与增长：使用带 `ann_date` 的财务指标，公告信息从公告日的下一个交易日起进入特征；
4. 行业与 ST：使用带生效日期的历史记录；
5. 1990～2005：交易所、监管机构、指数公司和主流官方媒体的历史资料。

所有原始文件、查询参数、覆盖日期、行数和 SHA-256 写入 `data_manifest.json`。任何 token 不得进入文件或日志。

### 3.3 数据门 D0

在计算风格前先逐月审计：股票数、退市股、特征可用率、行业覆盖率、极值和复权完整性。

- 六个特征族在某月均达到 80% 有效覆盖，且退市股链路可验证：该月进入主分析；
- 质量/增长覆盖不足，但规模、估值、趋势、风险、交易五族通过：该月进入五族敏感性分析，不能与六族主结果混作一条序列；
- 规模或退市覆盖不合格：该月不能做定量风格识别，研究起点顺延；对应早期区间改为定性映射；
- 若 2006～2009 无法通过 D0，必须明确缩短“定量覆盖”而不能用成交额代理总市值后仍声称是完整大小盘风格。

## 4. 状态发现方法

### 4.1 月度赢家画像

每个月得到六维赢家画像向量。每个维度使用仅截至当月可见历史的 expanding median/MAD 做稳健标准化，防止未来波动信息进入早期月份。

主聚类输入是月度画像本身。另生成 20 日和 60 日滚动画像，只用于检查急速切换和状态识别滞后，不参与状态数选择。

### 4.2 候选状态数

只比较 `K = 2, 3, 4, 5`。主算法为“聚类中心 + 时间切换惩罚”：

```text
objective = Σ distance(payoff_t, centroid[state_t])²
            + λ × Σ 1(state_t != state_t-1)
```

这相当于带持久性的状态聚类：每个月都能归类，同时避免普通 KMeans 把相邻月份切成大量一月事件。`λ` 候选固定为 `[0, 0.25, 0.5, 1, 2] × median(||payoff_t - payoff_{t-1}||²)`，使用 12 个月 block bootstrap 检查稳定性；不得根据 924 的标签效果挑选 `λ`。

每个 `K × λ` 使用固定随机种子 `[42, 1000, 2000, 3000, 4000]`，每种子 20 次初始化，取目标函数最小解，最终按匈牙利中心匹配消除 cluster label permutation。Ward 层次聚类作为算法敏感性检查；若两种方法的月度状态一致性过低，不能宣称风格划分稳健。

### 4.3 时间分工

| 区间 | 用途 |
|---|---|
| 2006～2020 | development；使用 expanding blocked folds 选择最小 K、切换惩罚和稳定性规则 |
| 2021～最新 | 冻结审计；不得返回修改 K 或阈值 |

development 内采用滚动起点：至少用 60 个月形成状态中心，再冻结中心分配之后 24 个月并评价 W/S 门，随后扩展训练窗继续下一折。`K/λ` 根据各折汇总结果决定；选定后使用截至 2020-12 的全部 development 月份重新估计中心，再一次性打开 2021 年后的冻结审计段。

若 D0 使定量起点晚于 2006，development 起点随之顺延，但 2021 年后的冻结审计段保持不变；若 2021 年前不足 60 个合格月份，则停止本协议并补数据，不能缩短到失去跨 episode 能力。所有 `K/λ` 和通过规则必须在读取 2021 年后状态结果前写入协议文件。

## 5. 最小状态数判定

从 `K=2` 开始，取第一个同时通过以下四道门的 K；通过后不再因为更高 K 的图形更漂亮而增加状态。

### 5.1 覆盖门 C

- 2006 年以来 100% 的合格月份被唯一分配；
- 冻结审计段到最近状态中心的 OOD 比例不超过 5%；
- 每个状态在 2006～2020 至少占 8% 的月份且不少于 18 个月；
- 每个状态至少出现于两个相隔 6 个月以上的 episode，避免把 2015 单独做成一个 development 状态；924 位于冻结审计段，不能参与这条门槛。

### 5.2 赢家差异门 W

对任意两种状态，必须同时满足：

1. 至少两个不同特征族的中心方向相反，且中心差超过该维历史波动的 0.5 倍；
2. 两个状态的赢家画像余弦相似度低于 0.5；
3. 用每个 expanding fold 训练部分的中心构造状态专属 winner portfolio，在该 fold 后续验证月份形成对角占优的跨状态收益矩阵：本状态收益比在对方状态至少高 4 个百分点年化，12 个月 block bootstrap 中该差异为正的概率至少为 80%。

winner portfolio 使用冻结状态中心对当月可见股票特征打分，做行业中性的 top decile 减 bottom decile；不能在每个状态内重新挑选最赚钱的单因子。

### 5.3 稳定性门 S

- 月度状态的中位连续期至少 3 个月；
- 12 个月 block bootstrap 的状态分配 Adjusted Rand Index 中位数至少 0.60；
- 主算法与 Ward 敏感性结果的中心匹配后 ARI 至少 0.50；
- 删除任意一个特征族后，最小 K 不增加超过 1，且状态核心解释不整体翻转。

### 5.4 简约门 P

- `K=2` 通过 C/W/S，则结论就是两种风格，不再测试“解释更丰富”的四状态方案；
- `K=2` 不通过时，记录具体失败门，再测试 `K=3`；依此直到 `K=5`；
- 若 `K=5` 仍不通过，正式结论是“不能用不超过五种稳定风格覆盖 A 股”，而不是强行选择表现最好的 K。

## 6. 防止循环论证

因为状态由股票类型收益发现，“本状态的股票类型在本状态赚钱”天然有一定同义反复。报告必须把证据分成三层：

1. **development 同期画像**：用于解释状态名称，不作为有效性证明；
2. **development blocked folds**：每折中心和 winner portfolio 均来自更早时期，只允许在后续月份分配状态，不允许重挑赢家；这是 W 门的主要证据；
3. **冻结审计段**：报告同期对角占优、状态 OOD 距离，以及“使用上月状态预测下月赢家”的 lagged payoff matrix。lagged 结果不作为覆盖硬门，但用于判断状态是否具有模型或策略应用价值。

924、2015 杠杆牛和其他知名行情只在状态冻结后映射，不参与状态数和中心选择。

## 7. 报告内容

最终报告至少包括：

1. 结论先行：最小 K，或“不存在 K≤5 的合格简化”；
2. 每种状态的赢家/输家画像、典型月份和不应混淆的相邻状态；
3. 2006 年以来逐月状态时间线，所有月份均有唯一标签；
4. 状态转移矩阵、连续期和出现频率；
5. 跨状态 winner payoff matrix 及 block-bootstrap 置信度；
6. 从 K=2 起到第一个通过者为止，每个已评估 K 的 C/W/S/P 结果；更高 K 标注为“因简约门未运行”；若没有通过者则完整报告 K=2～5；
7. 1990～2005 的定性映射与置信度；
8. 2007、2008～09、2014～15、2017、2019Q1、2020、2021～23、2024 微盘危机、924、2025～26 等 episode 的状态归属；
9. 2019Q1 与 924 的直接对比；
10. 在线识别延迟、OOD 月份、数据限制和不可用于调参的声明。

状态名称采用画像式命名，例如“低波质量防御”或“高波小盘投机”，不使用带褒贬或机制推断的名称，除非外部证据能够单独支持。

## 10. 验证要求

### 10.1 单元测试

- 月末特征严格早于收益窗口；
- 财务字段只在 `ann_date` 后可见；
- 退市股和历史成分不会因当前状态被删除；
- 截面标准化、行业/规模中性化和稳健回归输出方向正确；
- 聚类对 label permutation 不敏感；
- 切换惩罚为零和极大时行为符合预期；
- K 门在合成两状态、三状态和无稳定状态数据上给出正确结论；
- 每个合格月份恰有一个状态，OOD 比例计算正确；
- block bootstrap 保持连续时间块，不把月份独立重采样。

### 10.2 数据与报告验证

- `data_manifest.json` 中所有输入 SHA、日期和行数可复算；
- 月度 payoff、状态表、中心表和报告数字逐项一致；
- 2006 年以来没有未解释的月份；
- 报告明确区分同期、development blocked folds 和 lagged 预测三种口径；
- 从 K=2 到首个通过者的结果完整保留；若没有通过者，则 K=2～5 的失败结果全部保留；
- HTML 可本地打开，图表、表格和相对链接完整；
- 未启动模型训练、策略选型或 baseline 变更。

## 11. 验收标准

研究只有在以下条件全部满足时才算完成：

1. D0 数据门给出明确通过区间和缺口，不能隐含幸存者偏差；
2. 按 K=2→5 的预登记顺序评估至首个通过者；更高 K 不运行并明确记录，若全部失败则给出 K=2～5 的完整结果；
3. 输出满足全部门槛的最小 K，或明确否定 K≤5；
4. 定量覆盖所有合格月份，冻结审计段 OOD 不超过已定阈值；
5. 不同状态的赢家画像在 development blocked folds 满足 W 门，而不只是在同期样本看起来不同；
6. 1990～2005 全区间均完成有置信度标记的定性映射；
7. 所有结论可由冻结协议、manifest 和机器可读产物复现；
8. 结论不自动进入 B6-M 特征或 B4-S 策略。
